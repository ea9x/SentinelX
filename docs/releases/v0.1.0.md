# SentinelX v0.1.0 — experimental preview

Draft release notes. Preparing this file does not create a Git tag or GitHub Release. If published, mark the release **pre-release**.

## Included

- English and Arabic interface with right-to-left layout.
- Nmap, WhatWeb, OWASP ZAP, Nuclei and SSLyze integrations, installed separately.
- Persistent serial scan queue, cancellation, retained evidence and explicit incomplete/failure handling.
- Manual finding review, remediation tasks and comparisons that do not equate absence with remediation.
- PDF export, owner-scoped access and local encrypted backup verification.
- Windows loopback launcher and backend supervisor with documented shutdown procedure.
- Configuration templates, source-package checks, CI and contribution/security documentation.

## Validation snapshot

- A fresh Windows Python 3.12 installation passed 93 backend tests; 8 frontend translation tests and the frontend build passed.
- The public main-branch Source checks run passed on Windows/Linux backend jobs and the frontend job: [validation run](https://github.com/ea9x/SentinelX/actions/runs/40077637408).
- An isolated real SSLyze workflow exercised scan, certificate replacement, remediation, comparison and PDF export. A separate synthetic restore rehearsal preserved 12 tables, 20 rows and the PDF, with authenticated endpoint checks.
- A real supervisor rehearsal on an isolated fixture replaced a deliberately stopped child process in about 23 seconds.

This snapshot describes bounded checks of the source before the documentation update; it does not replace CI on the eventual release tag.

## Install

Use Python 3.12, Node 24 and a dedicated MySQL installation, then follow [Windows installation](../../INSTALL-WINDOWS.md). Generate private configuration locally and create the initial administrator through the local CLI. No default account, scanner runtimes, credentials or production data are included.

## Known limitations

- Experimental local deployment, not a production security certification or an independent audit.
- Local Flask/Vite HTTP serving is intended for loopback; do not expose it directly to the internet.
- Docker configuration has syntax validation only, without a complete build/run certification for this preview.
- Scanner alerts require review; coverage differs by tool, target protocol and authentication settings.
- No open-source license has been selected. The project owner retains rights to the original code; upstream tools retain their own licenses.
- Dependabot changes require individual review and testing before merging.

Source archives from GitHub are sufficient for the preview. Do not attach private installation archives, databases, generated customer reports or backups to a release.
